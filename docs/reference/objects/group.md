# Сообщество

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/reference/objects/group)

Объект содержит информацию о сообществе ВКонтакте. Набор полей может меняться в зависимости от вызванного метода и переданных в нем параметров.

## <a id="Базовые поля"></a>Базовые поля

### <a id="id"></a>`id`

`integer` Идентификатор сообщества.

### <a id="name"></a>`name`

`string` Название сообщества.

### <a id="screen_name"></a>`screen_name`

`string` Короткий адрес, например, `apiclub`.

### <a id="is_closed"></a>`is_closed`

`integer` Является ли сообщество закрытым. Возможные значения:

- `0` — открытое;
- `1` — закрытое;
- `2` — частное.

### <a id="deactivated"></a>`deactivated`

`string` Возвращается в случае, если сообщество удалено или заблокировано. Возможные значения:

- `deleted` — сообщество удалено;
- `banned` — сообщество заблокировано;

### <a id="is_admin"></a>`is_admin`

`integer` Требуется [`scope`](../../api/privacy.md#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0) = `groups` Информация о том, является ли текущий пользователь руководителем. Возможные значения:

- `1` — является;
- `0` — не является.

### <a id="admin_level"></a>`admin_level`

`integer` Требуется [`scope`](../../api/privacy.md#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0) = `groups` Уровень полномочий текущего пользователя (если `is_admin` = `1`):

- `1` — модератор;
- `2` — редактор;
- `3` — администратор.

### <a id="is_member"></a>`is_member`

`integer` Требуется [`scope`](../../api/privacy.md#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0) = `groups` Информация о том, является ли текущий пользователь участником. Возможные значения:

- `1` — является;
- `0` — не является.

### <a id="is_advertiser"></a>`is_advertiser`

`integer` Требуется [`scope`](../../api/privacy.md#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0) = `groups` Информация о том, является ли текущий пользователь рекламодателем. Возможные значения:

- `1` — является;
- `0` — не является.

### <a id="invited_by"></a>`invited_by`

`integer` Требуется [`scope`](../../api/privacy.md#%D0%9F%D1%80%D0%B0%D0%B2%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0) = `groups` Идентификатор пользователя, который отправил приглашение в сообщество. Поле возвращается только для метода [`groups.getInvites`](https://dev.vk.ru/ru/groups.getInvites).

### <a id="type"></a>`type`

`string` Тип сообщества:

- `group` — группа;
- `page` — публичная страница;
- `event` — мероприятие.

### <a id="photo_50"></a>`photo_50`

`string` URL главной фотографии с размером 50x50px.

### <a id="photo_100"></a>`photo_100`

`string` URL главной фотографии с размером 100х100px.

### <a id="photo_200"></a>`photo_200`

`string` URL главной фотографии в максимальном размере.

## <a id="Опциональные поля A-K"></a>Опциональные поля A-K

### <a id="activity"></a>`activity`

`string` Строка тематики паблика. У групп возвращается строковое значение, открыта ли группа или нет, а у событий дата начала.

### <a id="addresses"></a>`addresses`

`object` Информация об адресах сообщества. Возвращаются следующие поля:

- `is_enabled` (`boolean`) — включен ли блок адресов в сообществе.
- `main_address_id` (`integer`) — идентификатор основного адреса.

### <a id="age_limits"></a>`age_limits`

`integer` Возрастное ограничение.

- `1` — нет;
- `2` — 16+;
- `3` — 18+.

### <a id="ban_info"></a>`ban_info`

`object` Информация о занесении в черный список сообщества (поле возвращается только при запросе информации об одном сообществе). Объект, содержащий следующие поля:

- `end_date` (`integer`) — срок окончания блокировки в формате `unixtime`;
- `comment` (`string`) — комментарий к блокировке.

### <a id="can_create_topic"></a>`can_create_topic`

`integer` Информация о том, может ли текущий пользователь создать новое обсуждение в группе. Возможные значения:

- `1` — может;
- `0` — не может.

### <a id="can_message"></a>`can_message`

`integer` Информация о том, может ли текущий пользователь написать сообщение сообществу. Возможные значения:

- `1` — может;
- `0` — не может.

### <a id="can_post"></a>`can_post`

`integer` Информация о том, может ли текущий пользователь оставлять записи на стене сообщества. Возможные значения:

- `1` — может;
- `0` — не может.

### <a id="can_see_all_posts"></a>`can_see_all_posts`

`integer` Информация о том, разрешено ли видеть чужие записи на стене группы. Возможные значения:

- `1` — может;
- `0` — не может.

### <a id="can_upload_doc"></a>`can_upload_doc`

`integer` Информация о том, может ли текущий пользователь загружать документы в группу. Возможные значения:

- `1` — может;
- `0` — не может.

### <a id="can_upload_story"></a>`can_upload_story`

`integer` Информация о том, может ли текущий пользователь загружать истории от имени сообщества:

- `1` — может;
- `0` — не может.

### <a id="can_upload_video"></a>`can_upload_video`

`integer` Информация о том, может ли текущий пользователь загружать видеозаписи в группу. Возможные значения:

- `1` — может;
- `0` — не может.

### <a id="city"></a>`city`

`object` Город, указанный в информации о сообществе. Объект, содержащий следующие поля:

- `id` (`integer`) — идентификатор города;
- `title` (`string`) — название города.

### <a id="contacts"></a>`contacts`

`array` Информация из блока контактов публичной страницы. Массив объектов, каждый из которых может содержать поля:

- `user_id` (`integer`) — идентификатор пользователя;
- `desc` (`string`) — должность;
- `phone` (`string`) — номер телефона;
- `email` (`string`) — адрес e-mail.

### <a id="counters"></a>`counters`

`object` Объект, содержащий счётчики сообщества, может включать любой набор из следующих полей: `photos`, `albums`, `audios`, `videos`, `topics`, `docs`.

> Поле возвращается только при запросе данных об одном сообществе

### <a id="country"></a>`country`

`object` Страна, указанная в информации о сообществе. Объект, содержащий следующие поля:

- `id` (`integer`) — идентификатор страны;
- `title` (`string`) — название страны.

### <a id="cover"></a>`cover`

`object` Обложка сообщества. Объект, который содержит следующие поля:

- `enabled` (`integer`) — информация о том, включена ли обложка (`1` — да, `0` — нет);
- `images` (`array`) — копии изображений обложки. Массив объектов, каждый из которых содержит следующие поля:

  - `url` (`string`) — URL копии;
  - `width` (`integer`) — ширина копии;
  - `height` (`integer`) — высота копии.

### <a id="crop_photo"></a>`crop_photo`

`object` Возвращает данные о точках, по которым вырезаны профильная и миниатюрная фотографии сообщества.

- `photo` (`object`) — объект `photo` фотографии пользователя, из которой вырезается главное фото сообщества.
- `crop` (`object`) — вырезанная фотография сообщества. Содержит следующие поля:



  - `x` (`number`) — координата X левого верхнего угла в процентах;
  - `y` (`number`) — координата Y левого верхнего угла в процентах;
  - `x2` (`number`) — координата X правого нижнего угла в процентах;
  - `y2` (`number`) — координата Y правого нижнего угла в процентах.
- `rect` (`object`) — миниатюрная квадратная фотография, вырезанная из фотографии `crop`. Содержит набор полей, аналогичный объекту `crop`.

### <a id="description"></a>`description`

`string` Текст описания сообщества.

### <a id="fixed_post"></a>`fixed_post`

`integer` Идентификатор закрепленной записи. Получить дополнительные данные о записи можно методом [`wall.getById`](https://dev.vk.ru/ru/wall.getById), передав в поле `posts` `{group_id}{post_id}`.

### <a id="has_photo"></a>`has_photo`

`integer` Информация о том, установлена ли у сообщества главная фотография. Возможные значения:

- `1` — установлена;
- `0` — не установлена.

### <a id="is_favorite"></a>`is_favorite`

`integer` Информация о том, находится ли сообщество в закладках у текущего пользователя. Возможные значения:

- `1` — находится ;
- `0` — не находится.

### <a id="is_hidden_from_feed"></a>`is_hidden_from_feed`

`integer` Информация о том, скрыто ли сообщество из ленты новостей текущего пользователя. Возможные значения:

- `1` — скрыто ;
- `0` — не скрыто.

### <a id="is_messages_blocked"></a>`is_messages_blocked`

`integer` Информация о том, заблокированы ли сообщения от этого сообщества (для текущего пользователя).

## <a id="Опциональные поля L-W"></a>Опциональные поля L-W

### <a id="links"></a>`links`

`array` Информация из блока ссылок сообщества. Массив объектов, каждый из которых содержит следующие поля:

- `id` (`integer`) — идентификатор ссылки;
- `url` (`string`) — URL;
- `name` (`string`) — название ссылки;
- `desc` (`string`) — описание ссылки;
- `photo_50` (`string`) — URL изображения-превью шириной 50px;
- `photo_100` (`string`) — URL изображения-превью шириной 100px.

> Поле возвращается только при запросе данных об одном сообществе

### <a id="main_album_id"></a>`main_album_id`

`integer` Идентификатор основного фотоальбома.

### <a id="main_section"></a>`main_section`

`integer` Информация о главной секции. Возможные значения:

- `0` — отсутствует;
- `1` — фотографии;
- `2` — обсуждения;
- `3` — аудиозаписи;
- `4` — видеозаписи;
- `5` — товары.

### <a id="market"></a>`market`

`object` Информация о магазине. Объект, содержащий следующие поля:

- `enabled` (`integer`) — информация о том, включен ли блок товаров в сообществе. Возможные значения:

  - `1` — включен;
  - `0` — выключен. Если `enabled` = `0`, объект не содержит других полей.
- `type` (`string`) — информация о типе магазина. Возвращается, если в группе включен раздел "Товары". Возможные значения:

  - `basic` — базовые товары;
  - `advanced` — расширенные товары.
- `price_min` (`integer`) — минимальная цена товаров;
- `price_max` (`integer`)— максимальная цена товаров;
- `main_album_id` (`integer`) — идентификатор главной подборки товаров;
- `contact_id` (`integer`) — идентификатор контактного лица для связи с продавцом. Возвращается отрицательное значение, если для связи с продавцом используются сообщения сообщества;
- `currency` (`object`) — информация о валюте. Объект, содержащий поля:

  - `id` (`integer`) — идентификатор валюты;
  - `name` (`string`) — символьное обозначение;
- `currency_text` (`string`) — строковое обозначение.

### <a id="member_status"></a>`member_status`

`integer` `Требуется` `=` `groups` Статус участника текущего пользователя. Возможные значения:

- `0` — не является участником;
- `1` — является участником;
- `2` — не уверен, что посетит мероприятие;
- `3` — отклонил приглашение;
- `4` — запрос на вступление отправлен;
- `5` — приглашен.

### <a id="members_count"></a>`members_count`

`integer` Количество участников в сообществе

### <a id="place"></a>`place`

`object` Место, указанное в информации о сообществе. Объект, содержащий следующие поля:

- `id` (`integer`) — идентификатор места;
- `title` (`string`) — название места;
- `latitude` (`number`) — географическая широта в градусах (от -90 до 90);
- `longitude` (`number`) — географическая долгота в градусах (от -180 до 180);
- `type` (`string`) — тип места;
- `country` (`integer`) — идентификатор страны;
- `city` (`integer`) — идентификатор города;
- `address` (`string`) — адрес.

### <a id="public_date_label"></a>`public_date_label`

`string` Возвращается для публичных страниц. Текст описания для поля `start_date`.

### <a id="site"></a>`site`

`string` Адрес сайта из поля «веб-сайт» в описании сообщества.

### <a id="start_date и finish_date"></a>`start_date` и `finish_date`

Для встреч содержат время начала и окончания встречи в формате `unixtime`. Для публичных страниц содержит только `start_date` — дата основания в формате `YYYYMMDD`.

### <a id="status"></a>`status`

`string` Статус сообщества.

### <a id="trending"></a>`trending`

`integer` Информация о том, есть ли у сообщества «огонёк».

### <a id="verified"></a>`verified`

`integer` Верифицировано ли сообщество:

- `1` — верифицировано;
- `0` — нет.

Подробнее о верификации — в [Помощи ВКонтакте](https://vk.ru/away.php?to=https%3A%2F%2Fvk.com%2Ffaq18065).

### <a id="vk_ticket"></a>`vk_ticket`

`object` Информация о блоке покупки билета в сервисе VK Билеты. Объект, содержащий поля:

- `title` (`string`) — текст на кнопке. Например, «Купить билет».
- `description` (`string`) — описание действия. Например, «Ведёт к покупке в сервисе VK Билеты».
- `url` (`string`) — адрес страницы покупки билета. Адрес может содержать utm-метки и другие параметры.
- `is_onboarding_enabled` (`boolean`) — включён ли онбординг для сценария покупки:

  - `true` — онбординг включён.
  - `false` — онбординг выключен. Значение по умолчанию.

### <a id="wall"></a>`wall`

`integer` Стена. Возможные значения:

- `0` — выключена;
- `1` — открытая;
- `2` — ограниченная;
- `3` — закрытая.

### <a id="wiki_page"></a>`wiki_page`

`string` Название главной вики-страницы.
