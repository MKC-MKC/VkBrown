# Фотография

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/reference/objects/photo)

Объект, описывающий фотографию, содержит следующие поля:

## <a id="id "></a>`id`

`integer` Идентификатор фотографии.

## <a id="album_id "></a>`album_id`

`integer` Идентификатор альбома, в котором находится фотография.

## <a id="owner_id "></a>`owner_id`

`integer` Идентификатор владельца фотографии.

## <a id="user_id "></a>`user_id`

`integer` Идентификатор пользователя, загрузившего фото (если фотография размещена в сообществе). Для фотографий, размещенных от имени сообщества, `user_id` = `100`.

## <a id="text "></a>`text`

`string` Текст описания фотографии.

## <a id="date "></a>`date`

`integer` Дата добавления в формате Unixtime.

## <a id="thumb_hash "></a>`thumb_hash`

`string` Компактное представление заполнителя изображения. Можно использовать для показа во время загрузки реального изображения.

## <a id="has_tags "></a>`has_tags`

`boolean` Информация о том, имеет ли изображение теги.

## <a id="sizes "></a>`sizes`

`array` Массив с копиями изображения в разных размерах. Каждый объект массива содержит следующие поля:

- `type` (`string`) — тип копии. См. [Формат описания размеров фотографии](https://dev.vk.ru/ru/reference/objects/photo-sizes).
- `url` (`string`) — URL копии.
- `width` (`integer`) — высота в px.
- `height` (`integer`) — ширина в px.

## <a id="width* "></a>`width`\*

`integer` Ширина оригинала фотографии в пикселях.

## <a id="height* "></a>`height`\*

`integer` Высота оригинала фотографии в пикселях.

### <a id="id"></a>`id`

`integer` Идентификатор фотографии.

### <a id="album_id"></a>`album_id`

`integer` Идентификатор альбома, в котором находится фотография.

### <a id="owner_id"></a>`owner_id`

`integer` Идентификатор владельца фотографии.

`integer` Идентификатор пользователя, загрузившего фото (если фотография размещена в сообществе). Для фотографий, размещенных от имени сообщества, `user_id` = `100`.

`string` Текст описания фотографии.

### <a id="sizes"></a>`sizes`

`array` Массив с копиями изображения в разных размерах. Описание объекта находится [на отдельной странице](https://dev.vk.ru/ru/reference/objects/photo-sizes). Поле возвращается только при передаче параметра `photo_sizes` = `1` в запросе. Если параметр не передан, вместо поля `sizes` возвращаются поля, описанные ниже.

### <a id="photo_75"></a>`photo_75`

`string` URL копии фотографии с максимальным размером `75x75px`.

### <a id="photo_130"></a>`photo_130`

`string` URL копии фотографии с максимальным размером `130x130px`.

### <a id="photo_604"></a>`photo_604`

`string` URL копии фотографии с максимальным размером `604x604px`.

### <a id="photo_807"></a>`photo_807`

`string` URL копии фотографии с максимальным размером `807x807px`.

### <a id="photo_1280"></a>`photo_1280`

`string` URL копии фотографии с максимальным размером `1280x1024px`.

### <a id="photo_2560"></a>`photo_2560`

`string` URL копии фотографии с максимальным размером `2560x2048px`.

### <a id="width*"></a>`width`\*

`integer` Ширина оригинала фотографии в пикселях.

### <a id="height*"></a>`height`\*

`integer` Высота оригинала фотографии в пикселях.

\* — Значения могут быть недоступны для фотографий, загруженных на сайт до 2012 года.
