# Граффити

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/reference/objects/graffiti)

Объект, описывающий граффити, содержит следующие поля:

## <a id="id"></a>`id`

`integer` Идентификатор граффити.

## <a id="owner_id"></a>`owner_id`

`integer` Идентификатор пользователя, загрузившего графити.

## <a id="url"></a>`url`

`string` Адрес граффити, по которому его можно загрузить.

## <a id="width"></a>`width`

`integer` Ширина изображения в px.

## <a id="height"></a>`height`

`integer` Высота изображения в px.
