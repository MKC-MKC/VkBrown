# Комментарий на стене

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/reference/objects/comment)

Объект, описывающий комментарии на стене, содержит следующие поля:

### <a id="id"></a>`id`

`integer` Идентификатор комментария.

### <a id="from_id"></a>`from_id`

`integer` Идентификатор автора комментария.

### <a id="date"></a>`date`

`integer` Дата создания комментария в формате Unixtime.

### <a id="text"></a>`text`

`string` Текст комментария.

### <a id="donut"></a>`donut`

`object` Информация о VK Донат. Объект со следующими полями:

- `is_don` (`boolean`) — является ли комментатор подписчиком VK Донат.
- `placeholder` (`string`) — заглушка для пользователей, которые не оформили подписку VK Донат.

### <a id="reply_to_user"></a>`reply_to_user`

`integer` Идентификатор пользователя или сообщества, в ответ которому оставлен текущий комментарий (если применимо).

### <a id="reply_to_comment"></a>`reply_to_comment`

`integer` Идентификатор комментария, в ответ на который оставлен текущий (если применимо).

### <a id="attachments"></a>`attachments`

`array` Медиавложения комментария (фотографии, ссылки и т.п.). Описание массива `attachments` находится [на отдельной странице](video.md).

### <a id="parents_stack"></a>`parents_stack`

`array` Массив идентификаторов родительских комментариев.

### <a id="thread"></a>`thread`

`object` Информация о вложенной ветке комментариев, объект с полями:

- `count` (`integer`) — количество комментариев в ветке.
- `items` (`array`) — массив объектов комментариев к записи (только для метода [`wall.getComments`](https://dev.vk.ru/ru/wall.getComments)).
- `can_post` (`boolean`) – может ли текущий пользователь оставлять комментарии в этой ветке.
- `show_reply_button` (`boolean`) – нужно ли отображать кнопку «ответить» в ветке.
- `groups_can_post` (`boolean`) – могут ли сообщества оставлять комментарии в ветке.

## <a id="Версии API ниже 5.0"></a>Версии API ниже 5.0

Для [версий](../versions.md) ниже 5.0 названия полей и их структура отличаются от приведенных выше. Мы не рекомендуем использовать версии ниже 5.0.

### <a id="cid"></a>`cid`

`integer` Идентификатор комментария.

### <a id="from_id"></a>`from_id`

`integer` Идентификатор автора комментария.

### <a id="date"></a>`date`

`integer` Дата создания комментария в формате Unixtime.

### <a id="text"></a>`text`

`string` Текст комментария.

### <a id="reply_to_uid"></a>`reply_to_uid`

`integer` Идентификатор пользователя или сообщества, в ответ которому оставлен текущий комментарий (если применимо).

### <a id="reply_to_cid"></a>`reply_to_cid`

`integer` Идентификатор комментария, в ответ на который оставлен текущий (если применимо). Положительное число.

### <a id="attachments"></a>`attachments`

`array` Медиавложения комментария (фотографии, ссылки и т.п.). Описание массива `attachments` находится [на отдельной странице](attachments-wall.md).
