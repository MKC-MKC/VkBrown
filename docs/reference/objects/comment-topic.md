# Комментарий в обсуждении

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/reference/objects/comment-topic)

Объект, описывающий комментарий из обсуждения в сообществе, содержит следующие поля:

## <a id="id"></a>`id`

`integer` Идентификатор комментария.

## <a id="from_id"></a>`from_id`

`integer` Идентификатор автора комментария.

## <a id="date"></a>`date`

`integer` Дата создания (в формате Unixtime).

## <a id="text"></a>`text`

`string` Текст комментария.

## <a id="attachments"></a>`attachments`

`array` Медиавложения комментария (фотографии, ссылки и т.п.). Описание массива `attachments` находится [на отдельной странице](video.md).

## <a id="likes"></a>`likes`

`object` Информация об отметках «Мне нравится» текущего комментария (если был задан параметр `need_likes`), объект с полями:

- `count` (`integer`) — число пользователей, которым понравился комментарий,
- `user_likes` (`integer`) — наличие отметки «Мне нравится» от текущего пользователя (`1` — есть, `0` — нет),
- `can_like` (`integer`) — информация о том, может ли текущий пользователь поставить отметку «Мне нравится» (`1` — может, `0` — не может).
