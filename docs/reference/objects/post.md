# Запись на стене

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/reference/objects/post)

Объект, описывающий запись на стене пользователя или сообщества, содержит следующие поля:

### <a id="id"></a>`id`

`integer`

Идентификатор записи.

### <a id="owner_id"></a>`owner_id`

`integer`

Идентификатор владельца стены, на которой размещена запись. В [версиях](../versions.md) API ниже 5.7 это поле называется `to_id`.

### <a id="from_id"></a>`from_id`

`integer`

Идентификатор автора записи (от чьего имени опубликована запись).

### <a id="created_by"></a>`created_by`

`integer`

Идентификатор администратора, который опубликовал запись (возвращается только для сообществ при запросе с ключом доступа администратора). Возвращается в записях, опубликованных менее 24 часов назад.

### <a id="date"></a>`date`

`integer`

Время публикации записи в формате `unixtime`.

### <a id="text"></a>`text`

`string`

Текст записи.

### <a id="reply_owner_id"></a>`reply_owner_id`

`integer`

Идентификатор владельца записи, в ответ на которую была оставлена текущая.

### <a id="reply_post_id"></a>`reply_post_id`

`integer`

Идентификатор записи, в ответ на которую была оставлена текущая.

### <a id="friends_only"></a>`friends_only`

`integer`

`1`, если запись была создана с опцией «Только для друзей».

### <a id="comments"></a>`comments`

`object`

Информация о комментариях к записи, объект с полями:

- `count` (`integer`) — количество комментариев;
- `can_post*` (`integer`) — информация о том, может ли текущий пользователь комментировать запись (`1` — может, `0` — не может);
- `groups_can_post` (`integer`) — информация о том, могут ли сообщества комментировать запись;
- `can_close`(`boolean`) — может ли текущий пользователь закрыть комментарии к записи;
- `can_open`(`boolean`) — может ли текущий пользователь открыть комментарии к записи.

### <a id="copyright"></a>`copyright`

`object`

Источник материала, объект с полями:

- `id` (`integer`);
- `link*` (`string`);
- `name*` (`string`);
- `type*` (`string`).

### <a id="likes"></a>`likes`

`object`

Информация о лайках к записи, объект с полями:

- `count` (`integer`) — число пользователей, которым понравилась запись;
- `user_likes*` (`integer`) — наличие отметки «Мне нравится» от текущего пользователя (`1` — есть, `0` — нет);
- `can_like*` (`integer`) — информация о том, может ли текущий пользователь поставить отметку «Мне нравится» (`1` — может, `0` — не может);
- `can_publish*` (`integer`) — информация о том, может ли текущий пользователь сделать репост записи (`1` — может, `0` — не может).

### <a id="reposts"></a>`reposts`

`object`

Информация о репостах записи («Рассказать друзьям»), объект с полями:

- `count` (`integer`) — число пользователей, скопировавших запись;
- `user_reposted*` (`integer`) — наличие репоста от текущего пользователя (`1` — есть, `0` — нет).

### <a id="views"></a>`views`

`object`

Информация о просмотрах записи. Объект с единственным полем:

- `count` (`integer`) — число просмотров записи.

### <a id="post_type"></a>`post_type`

`string`

Тип записи, может принимать следующие значения: `post`, `copy`, `reply`, `postpone`, `suggest`.

### <a id="post_source"></a>`post_source`

`object`

Поле возвращается только для Standalone-приложений с ключом доступа, полученным ранее в Implicit Flow. С 25 июня 2024 года метод получения ключа пользователя Implicit Flow недоступен.

Информация о способе размещения записи. Описание объекта находится [на отдельной странице](https://dev.vk.ru/ru/reference/objects/post-source).

### <a id="attachments"></a>`attachments`

`array`

Массив объектов, соответствующих медиаресурсам, прикреплённым к записи: фотографиям, документам, видеофайлам и другим. Подробное описание — в разделе [Медиавложения в записях на стене](attachments-wall.md).

### <a id="geo"></a>`geo`

`object`

Информация о местоположении , содержит поля:

- `type` (`string`) — тип места;
- `coordinates` (`string`) — координаты места;
- `place` (`object`) — описание места (если оно добавлено). [Объект места](https://dev.vk.ru/ru/reference/objects/place).

### <a id="signer_id"></a>`signer_id`

`integer`

Идентификатор автора, если запись была опубликована от имени сообщества и подписана пользователем;

### <a id="copy_history"></a>`copy_history`

`array`

Массив, содержащий историю репостов для записи. Возвращается только в том случае, если запись является репостом. Каждый из объектов массива, в свою очередь, является объектом-записью стандартного формата.

### <a id="can_pin"></a>`can_pin`

`integer`

Информация о том, может ли текущий пользователь закрепить запись (`1` — может, `0` — не может).

### <a id="can_delete"></a>`can_delete`

`integer`

Информация о том, может ли текущий пользователь удалить запись (`1` — может, `0` — не может).

### <a id="can_edit"></a>`can_edit`

`integer`

Информация о том, может ли текущий пользователь редактировать запись (`1` — может, `0` — не может).

### <a id="is_pinned"></a>`is_pinned`

`integer`

Информация о том, что запись закреплена.

### <a id="marked_as_ads"></a>`marked_as_ads`

`integer`

Информация о том, содержит ли запись отметку «реклама» (`1` — да, `0` — нет).

### <a id="is_favorite"></a>`is_favorite`

`boolean`

`true`, если объект добавлен в закладки у текущего пользователя.

### <a id="donut"></a>`donut`

`object`

Информация о записи VK Донат:

- `is_donut` (`boolean`) — запись доступна только платным подписчикам VK Донат;
- `paid_duration` (`integer`) — время, в течение которого запись будет доступна только платным подписчикам VK Донат;
- `placeholder` (`object`) — заглушка для пользователей, которые не оформили подписку VK Донат. Отображается вместо содержимого записи.
- `can_publish_free_copy` (`boolean`) — можно ли открыть запись для всех пользователей, а не только подписчиков VK Донат;
- `edit_mode` (`string`) — информация о том, какие значения VK Донат можно изменить в записи. Возможные значения:

  - `all` — всю информацию о VK Донат.
  - `duration` — время, в течение которого запись будет доступна только платным подписчикам VK Донат.

### <a id="postponed_id"></a>`postponed_id`

`integer`

Идентификатор отложенной записи. Это поле возвращается тогда, когда запись стояла на таймере.
