# Беседа

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/reference/objects/conversation)

Объект описывает беседу с пользователем, сообществом или групповой чат. Содержит следующие поля:

## <a id="peer"></a>`peer`

`object` Информация о собеседнике. Объект, который содержит поля:

- `id` (`integer`) — идентификатор назначения.
- `type` (`string`) — тип. Возможные значения: `user`, `chat`, `group`, `email`
- `local_id` (`integer`) — локальный идентификатор назначения. Для чатов — `id` - 2000000000, для сообществ — -`id`, для email — -(`id`+2000000000).

## <a id="in_read"></a>`in_read`

`integer` Идентификатор последнего прочтенного входящего сообщения.

## <a id="out_read"></a>`out_read`

`integer` Идентификатор последнего прочтенного исходящего сообщения.

## <a id="unread_count"></a>`unread_count`

`integer` Число непрочитанных сообщений.

## <a id="important"></a>`important`

`boolean` `true`, если диалог помечен как важный (только для сообщений сообществ).

## <a id="unanswered"></a>`unanswered`

`boolean` `true`, если диалог помечен как неотвеченный (только для сообщений сообществ).

## <a id="push_settings"></a>`push_settings`

`object` Настройки Push-уведомлений. Объект, который содержит поля:

- `disabled_until` (`integer`) — timestamp, до которого оповещения отключены;
- `disabled_forever` (`boolean`) — передается в случае, если оповещения отключены навсегда, содержит `true`;
- `no_sound` (`boolean`) — передается в случае, если отключен звук оповещений, содержит `true`.

## <a id="can_write"></a>`can_write`

`object` Информация о том, может ли пользователь писать в диалог. Объект, который содержит поля:

- `allowed` (`boolean`) — `true`, если пользователь может писать в диалог;
- `reason` (`integer`) — код ошибки для `allowed` = `false`. Возможные значения:

  - `18` — пользователь заблокирован или удален;
  - `900` — нельзя отправить сообщение пользователю, который в чёрном списке;
  - `901` — пользователь запретил сообщения от сообщества;
  - `902` — пользователь запретил присылать ему сообщения с помощью настроек приватности;
  - `915` — в сообществе отключены сообщения;
  - `916` — в сообществе заблокированы сообщения;
  - `917` — нет доступа к чату;
  - `918` — нет доступа к e-mail;
  - `203` — нет доступа к сообществу.

## <a id="chat_settings"></a>`chat_settings`

`object` Настройки чата. Объект, который содержит поля:

- `members_count` (`integer`) — число участников;
- `title` (`string`) — название;
- `pinned_message` (`object`) — объект [закреплённого сообщения](pinned-message.md), если есть;
- `state` — (`string`) — статус текущего пользователя. Возможные значения:

  - `in` — состоит в чате;
  - `kicked` — исключён из чата;
  - `left` — покинул чат.
- `photo` (`objec`t) — изображение-обложка чата. Объект, который содержит поля:

  - `photo_50` (`string`) — URL изображения 50x50px;
  - `photo_100` (`string`) — URL изображения 100x100px;
  - `photo_200` (`string`) — URL изображения 200x200px;
  - `photo_base` (`string`) — URL изображения 400x400px, добавив GET-параметр `cs=<size>x<size>`, где size=`50`|`100`|`200` можно получить изображение соответствующего размера;
- `active_ids` (`array`) — идентификаторы последних пользователей, писавших в чат;
- `is_group_channel` (`boolean`) — информация о том, является ли беседа каналом сообщества.
