# messages.sendMessageEventAnswer

[Оглавление](../README.md) · [Оригинал VK](https://dev.vk.ru/ru/method/messages.sendMessageEventAnswer)

Отправляет событие с действием, которое произойдет при нажатии на callback-кнопку.

Для вызова метода можно использовать:

• [ключ доступа сообщества](../api/access-token/getting-started.md#%D0%9A%D0%BB%D1%8E%D1%87%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D1%81%D0%BE%D0%BE%D0%B1%D1%89%D0%B5%D1%81%D1%82%D0%B2%D0%B0) (требуются [права доступа](https://dev.vk.ru/ru/reference/access-rights): messages)

## <a id="Параметры"></a>Параметры

### event\_id

string

Случайная строка, которая возвращается в событии `message_event`.

Обязательный параметр

### user\_id

integer

Идентификатор пользователя.

Обязательный параметр

### peer\_id

integer

Идентификатор диалога со стороны сообщества.

Обязательный параметр

### event\_data

text

Объект действия, которое должно произойти после нажатия на кнопку.

## <a id="Результат"></a>Результат

После успешного выполнения возвращает `1`.

В ходе выполнения могут произойти [общие ошибки](../reference/errors.md)
