# photos.getUserPhotos

[Оглавление](../README.md) · [Оригинал VK](https://dev.vk.ru/ru/method/photos.getUserPhotos)

Возвращает список фотографий, на которых отмечен пользователь

Для вызова метода можно использовать:

• [ключ доступа пользователя](../api/access-token/getting-started.md#%D0%9A%D0%BB%D1%8E%D1%87%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D1%8F)

## <a id="Параметры"></a>Параметры

### user\_id

positive

Идентификатор пользователя, список фотографий для которого нужно получить.

### offset

positive

Смещение, необходимое для выборки определенного подмножества фотографий. По умолчанию — `0`.

### count

positive

Количество фотографий, которое необходимо получить.

### extended

checkbox

`1` — будут возвращены дополнительные поля `likes`, `comments`, `tags`, `can_comment`. Поля `comments` и `tags` содержат только количество объектов. По умолчанию данные поля не возвращается.

### sort

string

Сортировка результатов (`0` — по дате добавления отметки в порядке убывания, `1` — по дате добавления отметки в порядке возрастания).

## <a id="Результат"></a>Результат

После успешного выполнения возвращает список объектов [`photo`](../reference/objects/photo.md).

Если был задан параметр `extended`=`1`, возвращаются дополнительные поля:

- `likes` — количество отметок «Мне нравится» и информация о том, поставил ли лайк текущий пользователь;
- `comments` — количество комментариев к фотографии;
- `tags` — количество отметок на фотографии;
- `can_comment` — может ли текущий пользователь комментировать фото (`1` — может, `0` — не может).

Если был задан параметр `photo_size`=`1`, вместо полей `width` и `height` возвращаются размеры копий фотографии в [специальном формате](https://dev.vk.ru/ru/reference/objects/photo-sizes).
