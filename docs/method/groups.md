# Groups

[Оглавление](../README.md) · [Оригинал VK](https://dev.vk.ru/ru/method/groups)

[addAddress](groups.addAddress.md)

Позволяет добавить адрес в сообщество. Список адресов может быть получен методом [`groups.getAddresses`](https://dev.vk.ru/ru/method/groups.getAddresses).

> Для того, чтобы воспользоваться этим методом, вы должны быть администратором сообщества.

[addCallbackServer](groups.addCallbackServer.md)

Добавляет сервер для [Callback API](../api/callback/getting-started.md) в сообщество.

[approveRequest](https://dev.vk.ru/ru/method/groups.approveRequest)

Позволяет одобрить заявку в группу от пользователя.

[ban](https://dev.vk.ru/ru/method/groups.ban)

Добавляет пользователя или группу в черный список сообщества.

[deleteAddress](groups.deleteAddress.md)

Удаляет адрес сообщества.

[deleteCallbackServer](groups.deleteCallbackServer.md)

Удаляет сервер для [Callback API](../api/callback/getting-started.md) из сообщества.

[disableOnline](groups.disableOnline.md)

Выключает статус «онлайн» в сообществе.

[editAddress](groups.editAddress.md)

Метод редактирует адрес в сообществе. Чтобы получить список адресов, вызовите метод [`groups.getAddresses`](https://dev.vk.ru/ru/method/groups.getAddresses).

[editCallbackServer](groups.editCallbackServer.md)

Редактирует данные сервера для [Callback API](../api/callback/getting-started.md) в сообществе.

[editManager](https://dev.vk.ru/ru/method/groups.editManager)

Позволяет назначить/разжаловать руководителя в сообществе или изменить уровень его полномочий.

[enableOnline](groups.enableOnline.md)

Включает статус «онлайн» в сообществе.

[get](https://dev.vk.ru/ru/method/groups.get)

Возвращает список сообществ указанного пользователя.

[getAddresses](https://dev.vk.ru/ru/method/groups.getAddresses)

Метод возвращает адрес указанного сообщества.

[getBanned](groups.getBanned.md)

Возвращает список забаненных пользователей и сообществ в сообществе.

[getById](groups.getById.md)

Возвращает информацию о заданном сообществе или о нескольких сообществах.

[getCallbackConfirmationCode](groups.getCallbackConfirmationCode.md)

Позволяет получить строку, необходимую для подтверждения адреса сервера в [Callback API](../api/callback/getting-started.md).

[getCallbackServers](groups.getCallbackServers.md)

Получает информацию о серверах для [Callback API](../api/callback/getting-started.md) в сообществе.

[getCallbackSettings](groups.getCallbackSettings.md)

Позволяет получить настройки уведомлений [Callback API](../api/callback/getting-started.md) для сообщества.

[getCatalogInfo](https://dev.vk.ru/ru/method/groups.getCatalogInfo)

Возвращает список категорий для каталога сообществ.

[getInvitedUsers](https://dev.vk.ru/ru/method/groups.getInvitedUsers)

Возвращает список пользователей, которые были приглашены в группу.

[getInvites](https://dev.vk.ru/ru/method/groups.getInvites)

Данный метод возвращает список приглашений в сообщества и встречи текущего пользователя.

[getLongPollServer](groups.getLongPollServer.md)

Возвращает данные для подключения к [Bots Longpoll API](../api/bots-long-poll/getting-started.md).

[getLongPollSettings](groups.getLongPollSettings.md)

Получает настройки Bots Longpoll API для сообщества.

[getMembers](groups.getMembers.md)

Возвращает список участников сообщества.

[getOnlineStatus](groups.getOnlineStatus.md)

Получает информацию о статусе «онлайн» в сообществе.

[getRequests](https://dev.vk.ru/ru/method/groups.getRequests)

Возвращает список заявок на вступление в сообщество.

[getTagList](groups.getTagList.md)

Возвращает список тегов сообщества

[getTokenPermissions](groups.getTokenPermissions.md)

Возвращает настройки прав для ключа доступа сообщества.

[invite](https://dev.vk.ru/ru/method/groups.invite)

Позволяет приглашать друзей в группу.

[isMember](groups.isMember.md)

Возвращает информацию о том, является ли пользователь участником сообщества.

[removeUser](https://dev.vk.ru/ru/method/groups.removeUser)

Позволяет исключить пользователя из группы или отклонить заявку на вступление.

[search](https://dev.vk.ru/ru/method/groups.search)

Осуществляет поиск сообществ по заданной подстроке.

[setCallbackSettings](groups.setCallbackSettings.md)

Позволяет задать настройки уведомлений о событиях в [Callback API](../api/callback/getting-started.md).

[setLongPollSettings](groups.setLongPollSettings.md)

Задаёт настройки для Bots Long Poll API в сообществе.

[setSettings](groups.setSettings.md)

Устанавливает настройки сообщества

[setUserNote](groups.setUserNote.md)

Позволяет создать или отредактировать заметку о пользователе в рамках переписки пользователя с сообществом

[tagAdd](groups.tagAdd.md)

Позволяет добавить новый тег в сообщество.

[tagBind](groups.tagBind.md)

Позволяет «привязывать» и «отвязывать» теги сообщества к беседам.

[tagDelete](groups.tagDelete.md)

Позволяет удалить тег сообщества.

[tagUpdate](groups.tagUpdate.md)

Позволяет переименовать существующий тег.

[toggleMarket](https://dev.vk.ru/ru/method/groups.toggleMarket)

Переключает функционал раздела «Товаров» в выбранной группе.

[unban](https://dev.vk.ru/ru/method/groups.unban)

Убирает пользователя или группу из черного списка сообщества.
