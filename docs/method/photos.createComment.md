# photos.createComment

[Оглавление](../README.md) · [Оригинал VK](https://dev.vk.ru/ru/method/photos.createComment)

Создает новый комментарий к фотографии.

Для вызова метода можно использовать:

• ключ доступа пользователя, полученный в Standalone‑приложении через [Implicit Flow](https://dev.vk.ru/ru/api/access-token/implicit-flow-user) (требуется [право доступа](https://dev.vk.ru/ru/reference/access-rights): photos — выдаётся в исключительных случаях через запрос в поддержку по электронной почте [devsupport@corp.vk.com](mailto:devsupport@corp.vk.com))

## <a id="Параметры"></a>Параметры

### owner\_id

string

Идентификатор пользователя или сообщества, которому принадлежит фотография.

> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id`=`-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.ru/away.php?to=https%3A%2F%2Fvk.com%2Fapiclub) (club1).

### photo\_id

string

Идентификатор фотографии.

Обязательный параметр

### message

string

Текст комментария (является обязательным, если не задан параметр `attachments`).

Максимальное количество символов: **2048**.

### attachments

string

Список объектов, приложенных к комментарию и разделённых символом `«,»`. Поле `attachments` представляется в формате:

 `<type><owner_id>_<media_id>,<type><owner_id>_<media_id>`

`<type>` — тип медиа-вложения:

- `photo` — фотография
- `video` — видеозапись
- `audio` — аудиозапись
- `doc` — документ

`<owner_id>` — идентификатор владельца медиа-вложения `<media_id>` — идентификатор медиа-вложения.

Например:

 `photo100172_166443618,photo66748_265827614`

Параметр является обязательным, если не задан параметр `message`.

### from\_group

checkbox

Данный параметр учитывается, если `owner_id` \<`0` (комментарий к фотографии группы). Возможные значения:

- `1` — комментарий будет опубликован от имени группы;
- `0` — комментарий будет опубликован от имени пользователя.

По умолчанию: `0`.

### reply\_to\_comment

string

Идентификатор комментария, в ответ на который нужно оставить текущий.

### sticker\_id

positive

Идентификатор стикера, который нужно прикрепить к комментарию.

### access\_key

string

Ключ доступа.

### guid

string

Уникальное значение для предотвращения повторной отправки одного и того же комментария.

## <a id="Результат"></a>Результат

После успешного выполнения возвращает идентификатор созданного комментария.
