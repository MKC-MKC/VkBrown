# groups.getMembers

[Оглавление](../README.md) · [Оригинал VK](https://dev.vk.ru/ru/method/groups.getMembers)

Возвращает список участников сообщества.

Для вызова метода можно использовать:

• [ключ доступа пользователя](../api/access-token/getting-started.md#%D0%9A%D0%BB%D1%8E%D1%87%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D1%8F)

• [ключ доступа сообщества](../api/access-token/getting-started.md#%D0%9A%D0%BB%D1%8E%D1%87%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D1%81%D0%BE%D0%BE%D0%B1%D1%89%D0%B5%D1%81%D1%82%D0%B2%D0%B0)

• [сервисный ключ доступа](../api/access-token/getting-started.md#%D0%A1%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BB%D1%8E%D1%87%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0)

## <a id="Параметры"></a>Параметры

### group\_id

string

Идентификатор или короткое имя сообщества.

### sort

string

Сортировка, с которой необходимо вернуть список участников. Может принимать значения:

- `id_asc` — в порядке возрастания ID;
- `id_desc` — в порядке убывания ID;
- `time_asc` — в хронологическом порядке по вступлению в сообщество;
- `time_desc` — в антихронологическом порядке по вступлению в сообщество.

Сортировка по `time_asc` и `time_desc` возможна только при вызове от модератора сообщества.

### offset

positive

Смещение, необходимое для выборки определённого подмножества участников. По умолчанию `0`.

### count

positive

Количество участников сообщества, информацию о которых необходимо получить.

### fields

string

Список дополнительных полей, которые необходимо вернуть. Доступные значения:

- `bdate`;
- `can_post`;
- `can_see_all_posts`;
- `can_see_audio`;
- `can_write_private_message`;
- `city`;
- `common_count`;
- `connections`;
- `contacts`;
- `country`;
- `domain`;
- `education`;
- `has_mobile`;
- `last_seen`;
- `lists`;
- `online`;
- `online_mobile`;
- `photo_100`;
- `photo_200`;
- `photo_200_orig`;
- `photo_400_orig`;
- `photo_50`;
- `photo_max`;
- `photo_max_orig`;
- `relation`;
- `relatives`;
- `schools`;
- `sex`;
- `site`;
- `status`;
- `universities`.

### filter

string

- `friends` — будут возвращены только друзья в этом сообществе.
- `unsure` — будут возвращены пользователи, которые выбрали «Возможно пойду» (если сообщество относится к мероприятиям).
- `managers` — будут возвращены только руководители сообщества (доступно при запросе с передачей `access_token` от имени администратора сообщества).
- `donut` — будут возвращены только доны (пользователи, у которых есть платная подписка VK Donut).
- `unsure_friends` — будут возвращены друзья в этом сообществе, которые выбрали «Возможно пойду» (если сообщество относится к мероприятиям).
- `invites` — будут возвращены пользователи, приглашенные в мероприятие.

## <a id="Результат"></a>Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` (`integer`) и массив идентификаторов пользователей в поле `items` (`integer`).

Если был передан параметр `filter`=`managers`, возвращается дополнительное поле `role` (`string`), которое содержит уровень полномочий руководителя:

- `advertiser` — рекламодатель;
- `moderator` — модератор;
- `editor` — редактор;
- `administrator` — администратор;
- `creator` — создатель сообщества.
