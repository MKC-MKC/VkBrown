# market.getProductPhotoUploadServer

[Оглавление](../README.md) · [Оригинал VK](https://dev.vk.ru/ru/method/market.getProductPhotoUploadServer)

Возвращает адрес для [загрузки изображений товаров в сообщество](../api/upload/photo-in-market.md).

**Примечание.** Для успешной работы метода включите раздел **Товары** в сообществе:

1. Войдите ВКонтакте под своими учётными данными.
2. Откройте сообщество, в котором являетесь администратором.
3. В меню справа перейдите в **Управление → Разделы**.
4. На следующей странице, в блоке **Товары**, включите режим **Базовые** или **Расширенные**.
5. Нажмите **Сохранить**.

Для вызова метода можно использовать:

• [ключ доступа пользователя](../api/access-token/getting-started.md#%D0%9A%D0%BB%D1%8E%D1%87%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D1%8F) (требуется [право доступа](https://dev.vk.ru/ru/reference/access-rights): market — выдаётся в исключительных случаях через запрос в поддержку по электронной почте [devsupport@corp.vk.com](mailto:devsupport@corp.vk.com))

## <a id="Параметры"></a>Параметры

### group\_id

integer

Идентификатор сообщества, которому принадлежит желаемый товар. [Где найти идентификатор сообщества?](https://vk.ru/away.php?to=https%3A%2F%2Fvk.com%2Ffaq18062)

Обязательный параметр

### bulk

checkbox

Указывает, нужно ли загрузить несколько файлов. Если передаётся `true`, то в ответе вернётся адрес сервера, на который можно загрузить до 5 фотографий.

## <a id="Результат"></a>Результат

Возвращает объект с полем `upload_url`, которое содержит адрес для [загрузки изображений](../api/upload/photo-in-market.md).

```json
{
  "response":{
    "upload_url":"https://pu.vk.com/c857008/ss2158/upload.php?act=do_add&mid=743784474&aid=-53&gid=218252175&hash=39db9a3676d5ecc9b39bc7ab79a50ca7&rhash=4c9dc359457c26d9ecc32c94272f3239&swfupload=1&api=1&market_photo=1"
  }
}
```
