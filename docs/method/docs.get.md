# docs.get

[Оглавление](../README.md) · [Оригинал VK](https://dev.vk.ru/ru/method/docs.get)

Возвращает расширенную информацию о документах пользователя или сообщества.

Для вызова метода можно использовать:

• [ключ доступа пользователя](../api/access-token/getting-started.md#%D0%9A%D0%BB%D1%8E%D1%87%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0%20%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D1%8F) (требуется [право доступа](https://dev.vk.ru/ru/reference/access-rights): docs — выдаётся в исключительных случаях через запрос в поддержку по электронной почте [devsupport@corp.vk.com](mailto:devsupport@corp.vk.com))

## <a id="Параметры"></a>Параметры

### count

positive

Количество документов, информацию о которых нужно вернуть. По умолчанию: все документы. Максимальное количество документов, которое можно получить: 2000.

### offset

positive

Смещение, необходимое для выборки определенного подмножества документов. Максимальное значение: `1999`.

### type

positive

Тип файла. Возможные значения:

- `1` — текстовые документы.
- `2` — архивы.
- `3` — gif.
- `4` — изображения.
- `5` — аудио.
- `6` — видео.
- `7` — электронные книги.
- `8` — неизвестный тип.

### owner\_id

integer

Идентификатор пользователя или сообщества, которому принадлежат документы.

> Обратите внимание, идентификатор сообщества в параметре `owner_id` необходимо указывать со знаком `«-»` — например, `owner_id=-1` соответствует идентификатору сообщества [ВКонтакте API](https://vk.ru/away.php?to=https%3A%2F%2Fvk.com%2Fapiclub) (club1).

### return\_tags

checkbox

`1` — добавить в ответ массив меток документа.

## <a id="Результат"></a>Результат

После успешного выполнения возвращает объект, содержащий число результатов в поле `count` и массив объектов [файлов](../reference/objects/doc.md) в поле `items`.
