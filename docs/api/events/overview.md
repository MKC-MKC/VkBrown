# События в реальном времени

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/api/events/overview)

API ВКонтакте позволяет работать с событиями пользователя или сообщества в реальном времени. Это нужно для отображения нового сообщения, для моментальной реакции на комментарий в сообществе, для создания [чат-ботов](../bots/overview.md) или для анализа текстовых данных.

## <a id="Для сообществ"></a>Для сообществ

Для работы с событиями сообществ мы предлагаем два разных подхода:

- [Callback API](../callback/getting-started.md) — в этом случае мы будем отправлять уведомление на ваш сервер о каждом новом событии.
- [Bots Long Poll API](../bots-long-poll/getting-started.md) — очередь из событий хранится на стороне ВКонтакте, вы получаете их, используя Long Polling запросы.

Callback API и Bots Long Poll API поддерживают события, связанные с сообщениями сообщества, активностью пользователей на стене и в остальных разделах вашей группы или публичной страницы. Полный список событий в сообществах вы можете найти [на этой странице](../community-events/json-schema.md).

## <a id="Для пользователей"></a>Для пользователей

[User Long Poll API](../user-long-poll/getting-started.md) нужен для работы с событиями пользователя в вашем приложении. Очередь из событий хранится на стороне ВКонтакте, вы получаете их, используя Long Polling запросы.

User Long Poll API поддерживает все события, связанные с личными сообщениями (получение, редактирование, удаление), изменение статуса онлайн или счётчиков в меню.
