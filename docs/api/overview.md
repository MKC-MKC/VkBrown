VK API — это набор методов для работы с объектами экосистемы VK. Каждый метод выполняет определённую операцию: получить, создать, изменить или удалить данные. Методы сгруппированы по секциям в соответствии с предметной областью.

У каждого метода есть название и набор входных параметров. Параметры, типы данных и ограничения указаны на странице соответствующего метода.

- [Методы API](https://dev.vk.ru/ru/method)
- [Объекты](../reference/objects.md)

При успешном выполнении API возвращает объект в формате JSON с результатом запроса. Если возникает ошибка, API возвращает JSON с описанием ошибки.

- [Коды ошибок](../reference/errors.md)

## <a id="Авторизация"></a>Авторизация

Для вызова методов VK API используются ключи доступа, полученные по протоколу OAuth 2.1. Ключ доступа передаётся в каждом запросе в заголовке Authorization и определяет:

- Контекст запроса — от имени пользователя, приложения или сообщества.
- Права доступа — набор разрешённых действий, полученных при авторизации.

Используются следующие типы ключей доступа:

- [Сервисный ключ доступа](https://dev.vk.ru/ru/api/access-token/service-token)
- [Ключ доступа пользователя](access-token/user-token.md)
- [Ключ доступа сообщества](https://dev.vk.ru/ru/api/access-token/community-token)

Способ получения ключа доступа также зависит от типа приложения. Приложение можно создать либо в [кабинете сервиса авторизации VK ID](https://vk.ru/away.php?to=https%3A%2F%2Fid.vk.com%2Fabout%2Fbusiness%2Fgo) (Standalone-приложение), либо на [портале для разработчиков dev.vk.com](https://vk.ru/away.php?to=https%3A%2F%2Fdev.vk.com%2Fru%2Fadmin%2Fapps-list) (игра или мини-приложение).

Подробнее об авторизации — в разделе [Ключи доступа](access-token/getting-started.md).

## <a id="Права доступа"></a>Права доступа

Права доступа определяют, к каким данным и разделам API может обращаться приложение. Например, чтобы получить номер телефона пользователя, нужен ключ доступа с правом `phone`. Список прав, необходимых приложению, передаётся в параметре `scope` при получении ключа доступа.

Запрашивайте только те права, которые необходимы для работы сценариев приложения. Подробнее — в разделе [Права доступа и приватность](privacy.md).

### <a id="Данные профиля в VK ID"></a>Данные профиля в VK ID

Отдельно выделяются права доступа, связанные с данными профиля в [VK ID](https://vk.ru/away.php?to=https%3A%2F%2Fid.vk.ru%2F).

Базовые права доступны после создания приложения в [сервисе авторизации VK ID](https://vk.ru/away.php?to=https%3A%2F%2Fid.vk.com%2Fabout%2Fbusiness%2Fgo%2F):

- Имя, фамилия, фото профиля, пол, дата рождения, почта.

Расширенные права требуют подтверждения профиля бизнеса в VK ID:

- Номер телефона.

> Часть расширенных прав, например доступ к отдельным пользовательским данным, может выдаваться после индивидуального согласования. Для запроса таких прав напишите на [devsupport@corp.vk.com](mailto:devsupport@corp.vk.com).

Подробнее о получении доступа к данным профиля VK ID — в [документации VK ID](https://vk.ru/away.php?to=https%3A%2F%2Fid.vk.com%2Fabout%2Fbusiness%2Fgo%2Fdocs%2Fru%2Fvkid%2Flatest%2Fvk-id%2Fconnection%2Fcreate-application%23Nastrojka-dostupov).
