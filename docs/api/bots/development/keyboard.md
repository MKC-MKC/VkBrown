# Обзор

[Оглавление](../../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/api/bots/development/keyboard)

Клавиатура чат-бота — блок с кнопками, который отображается в интерфейсе сообщений и помогает пользователю взаимодействовать с ботом без ввода текста.


Клавиатуру можно настраивать: количество кнопок, подписи, цвета и действия. Это позволяет строить меню и сценарии, которые зависят от контекста диалога.

## <a id="Типы клавиатур"></a>Типы клавиатур

Поле `inline` в [объекте](keyboard.md#%D0%9E%D0%B1%D1%8A%D0%B5%D0%BA%D1%82%20%D0%BA%D0%BB%D0%B0%D0%B2%D0%B8%D0%B0%D1%82%D1%83%D1%80%D1%8B), описывающем клавиатуру, указывает тип клавиатуры.

### <a id="Клавиатура чата"></a>Клавиатура чата

Если `"inline": false`, то клавиатура располагается под полем ввода текста в окне чата.


Ограничения:

- До 40 кнопок.
- До 10 рядов по 5 кнопок.

### <a id="Inline-клавиатура"></a>Inline-клавиатура

Если `"inline": true`, клавиатура показывается в поле сообщения.


Ограничения:

- До 10 кнопок.
- До 6 рядов по 5 кнопок.

## <a id="Общие правила отображения"></a>Общие правила отображения

- Высота всех кнопок одинаковая.
- Кнопки, расположенные в одной строке, имеют одинаковую ширину.
- Ширина каждой строки равна ширине клавиатуры.
- Текст отображается по центру кнопки и обрезается, если не помещается в границы кнопки полностью.

## <a id="Параметры клавиатуры"></a>Параметры клавиатуры

Клавиатура передаётся в параметре `keyboard` метода [`messages.send`](../../../method/messages.send.md) в виде JSON-строки.

Пример:

```json
{
  "inline": false,
  "one_time": false,
  "buttons": [
    [
      {
        "action": {
          "type": "text",
          "label": "Помощь",
          "payload": "{\"cmd\":\"help\"}"
        },
        "color": "secondary"
      }
    ]
  ]
}
```

### <a id="Объект клавиатуры"></a>Объект клавиатуры

| Поле | Тип | Описание |
| --- | --- | --- |
| `buttons` *обязательное* | `array` | Массив рядов. Каждый ряд — массив кнопок. |
| `one_time` | `bool` | Скрывать клавиатуру после нажатия (`true/false`). Работает только при `inline: false`. |
| `inline` | `bool` | Тип клавиатуры: `false` — под полем ввода, `true` — внутри сообщения. |

### <a id="Объект кнопки"></a>Объект кнопки

| Поле | Тип | Описание |
| --- | --- | --- |
| `action` *обязательное* | `object` | Действие кнопки. Типы действий описаны в разделе [Типы кнопок](keyboard/key-types.md). |
| `color` | `string` | Цвет кнопки. Используется только для кнопок `text` и `callback`. |

### <a id="Цвета кнопок"></a>Цвета кнопок

| Значение | Назначение | Цвет в светлой теме | Цвет в тёмной теме |
| --- | --- | --- | --- |
| `primary` | Основное действие | `#5181B8` | `#E1E3E6` |
| `secondary` | Обычная кнопка | `#E5EBF1` | `#424242` |
| `negative` | Отмена/опасное действие | `#E64646` | `#FF5C5C` |
| `positive` | Подтверждение | `#4BB34B` | `#4BB34B` |

## <a id="Особенности работы"></a>Особенности работы

- Чтобы убрать клавиатуру из чата, отправьте пустой набор кнопок в параметре `keyboard`:



  ```json
  {
    "buttons": []
  }
  ```
- Проверяйте `payload` на сервере. Значения `payload`, указанные в кнопках, приходят в событиях бота. Пользователь может подменить `payload` вручную, поэтому проверяйте входящие данные и обрабатывайте только допустимые значения.
- Если в настройках сообщества включена кнопка «Начать», то при первом диалоге пользователь отправит команду `start`. `payload` будет выглядеть так:



  ```json
  {"command":"start"}
  ```
