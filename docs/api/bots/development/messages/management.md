## <a id="Работа с conversation_message_id"></a>Работа с `conversation_message_id`

Параметр `conversation_message_id` позволяет взаимодействовать боту с сообщениями без использования общего идентификатора сообщения, который может отсутствовать в некоторых случаях.

С помощью метода [`messages.getByConversationMessageId`](https://dev.vk.ru/ru/method/messages.getByConversationMessageId) можно получить информацию о сообщении по `conversation_message_id`. У бота должен быть доступ к переписке.

Бот имеет доступ к:

- Сообщениям в личном диалоге с ботом.
- Исходящим сообщениям бота.
- Сообщениям, отправленным после того, как бот получил доступ к переписке. Доступ появляется, если:



  - Бота упомянули в сообщении.
  - Сообщение начинается с символа `/`.
  - Боту выдали права на просмотр всех сообщений.

> В некоторых методах параметр `conversation_message_id` называется `cmid`.

## <a id="Редактирование"></a>Редактирование

Для редактирования сообщения используйте метод [`messages.edit`](../../../../method/messages.edit.md). В параметре `conversation_message_id` передайте идентификатор сообщения.

Необходимый идентификатор сообщения можно заранее получить с помощью метода [`messages.send`](../../../../method/messages.send.md) с параметром `peer_ids` и версией API не ниже 5.124.

## <a id="Удаление"></a>Удаление

Для удаления сообщения вызовите метод [`messages.delete`](../../../../method/messages.delete.md) с параметрами `peer_id`, `cmids` и `delete_for_all`.

## <a id="Закрепление"></a>Закрепление

Метод [`messages.pin`](https://dev.vk.ru/ru/method/messages.pin) позволяет закрепить сообщение в беседе. Для закрепления нужного сообщения воспользуйтесь параметром `conversation_message_id`.
