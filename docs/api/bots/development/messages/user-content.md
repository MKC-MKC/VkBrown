# Пользовательский контент и шаблоны

[Оглавление](../../../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/api/bots/development/messages/user-content)

## <a id="Сообщения с пользовательским контентом"></a>Сообщения с пользовательским контентом

При отправке сообщений, содержащих пользовательский контент, необходимо передавать его источник. Это может быть фотография из альбома, запись, комментарий, сообщение.

Наличие источника позволит избежать блокировок, если пользователи будут отправлять запрещённые [правилами платформы](https://vk.ru/away.php?to=https%3A%2F%2Fvk.com%2Fterms) материалы, и может быть полезно ботам, пересылающим пользовательский контент.

Информацию об источнике контента нужно передавать в методе [`messages.send`](../../../../method/messages.send.md), в параметре `content_source`.

### <a id="Параметр content_source"></a>Параметр `content_source`

В параметре `content_source` передаётся объект, описывающий источник пользовательского контента для чат-ботов.

Если источником является другое сообщение, например, сообщение от пользователя боту:

```json
{
  "type": "message",
  "owner_id": 0,
  "peer_id": 0,
  "conversation_message_id": 0
}
```

- `owner_id` — от чьего имени указан `peer_id`, например, можно использовать контент из сообщения другой группы.
- `peer_id` — идентификатор диалога.
- `conversation_message_id` — идентификатор сообщения в беседе. Не путайте с `message.id` профиля.

Если источником является любой другой контент на платформе, например, комментарий, пост, фотография:

```json
{
  "type": "url",
  "url": "https://vk.ru/…"
}
```

## <a id="Шаблоны сообщений"></a>Шаблоны сообщений

Боты могут отправлять специальные сообщения, используя шаблоны. Такие сообщения отличаются от обычных как по внешнему виду, так и по функциональности. На данный момент поддерживается один шаблон — карусель.

### <a id="Карусель"></a>Карусель

Это шаблон сообщения, который содержит несколько элементов. Элементы карусели можно скролить горизонтально.


Элемент карусели может состоять из заголовка, подзаголовка, картинки и кнопок. Нажатие на каждый из элементов карусели может сопровождаться выполнением действия: например, по нажатию на элемент карусели можно открыть ссылку.

Структурно все элементы карусели должны быть одинаковыми, при этом первый элемент определяет структуру остальных.

### <a id="Отправка карусели"></a>Отправка карусели

Чтобы отправить от имени бота сообщение с каруселью, вызовите метод [`messages.send`](../../../../method/messages.send.md), передав в параметр `template` объект следующего вида:

```json
{
  "type": "carousel",
  "elements": [
    "element1",
    "element2",
    "element3"
  ]
}
```

В объекте элемента карусели обязательно должны присутствовать поля:

- `buttons`
- `photo_id` или `title`
- `description`, если указан `title`

Остальные поля необязательные.

Учитывайте, что параметр `message` метода `messages.send` обязательный для сообщений с каруселью.

Максимальное количество элементов в карусели — `10`, минимальное — `1`.

### <a id="Поля элемента карусели"></a>Поля элемента карусели

- `title` (`string`) — заголовок, максимальная длина 80 символов.
- `description` (`string`) — подзаголовок, максимальная длина 80 символов.
- `photo_id` (`string`) — идентификатор прикрепляемого изображения.



  Требования к изображению:



  - Пропорции: 13/8.
  - Минимальный размер: 221×136 px.



  Изображения загружаются так же, как и [загрузка фотографии](attachments.md#%D0%97%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D0%BA%D0%B0%20%D1%84%D0%BE%D1%82%D0%BE%D0%B3%D1%80%D0%B0%D1%84%D0%B8%D0%B8).
- `buttons` (`array`) — массив с кнопками. Можно передать любые кнопки, которые описаны в разделе [Клавиатура](../keyboard.md). Один элемент карусели может содержать не больше 3 кнопок.
- `action` (`object`) — объект, описывающий действие при нажатии на элемент карусели. Поддерживается два действия:



  - `open_link` — открыть ссылку из поля `link`.
  - `open_photo` — открыть фото текущего элемента карусели.

### <a id="Примеры"></a>Примеры

#### <a id="Элемент карусели"></a>Элемент карусели

```json
{
  "title": "Title",
  "description": "Description",
  "action": {
    "type": "open_link",
    "link": "https://vk.ru"
  },
  "photo_id": "-109837093_457242809",
  "buttons": [
    {
      "action": {
        "type": "text",
        "label": "Label"
      }
    }
  ]
}
```

#### <a id="Указание действия"></a>Указание действия

```json
{"type": "open_link", "link": "https://vk.com"}
{"type": "open_photo"}
```

#### <a id="Объект template"></a>Объект `template`

```json
{
  "type": "carousel",
  "elements": [
    {
      "photo_id": "-109837093_457242811",
      "action": { "type": "open_photo" },
      "buttons": [
        {
          "action": {
            "type": "text",
            "label": "Текст кнопки 🌚",
            "payload": "{}"
          }
        }
      ]
    },
    {
      "photo_id": "-109837093_457242811",
      "action": { "type": "open_photo" },
      "buttons": [
        {
          "action": {
            "type": "text",
            "label": "Текст кнопки 2",
            "payload": "{}"
          }
        }
      ]
    },
    {
      "photo_id": "-109837093_457242811",
      "action": { "type": "open_photo" },
      "buttons": [
        {
          "action": {

        }
      ]
    }
  ]
}
```

### <a id="Обратная совместимость"></a>Обратная совместимость

Карусели могут быть недоступны пользователю, например, если он использует старую версию приложения ВКонтакте. При отправке лучше проверить, доступна ли пользователю эта функциональность. Если нет, отправьте информацию в обычном сообщении.

Подробнее — в разделе [Информация о возможностях клиента](../../getting-started.md#%D0%98%D0%BD%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%86%D0%B8%D1%8F%20%D0%BE%20%D0%B2%D0%BE%D0%B7%D0%BC%D0%BE%D0%B6%D0%BD%D0%BE%D1%81%D1%82%D1%8F%D1%85%20%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%B0).
