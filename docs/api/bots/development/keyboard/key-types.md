# Типы кнопок

[Оглавление](../../../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/api/bots/development/keyboard/key-types)

Клавиатура бота может содержать кнопки разных типов. Тип кнопки, указанный в поле `type`, определяет её название.

## <a id="text"></a>text

Отправляет сообщение с текстом из поля `label`.

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` *обязательное* | `string` | Тип кнопки. Значение: `text`. |
| `label` *обязательное* | `string` | Текст, который будет отправлен в сообщении и отображён на кнопке.Максимальная длина — 40 символов. |
| `payload` *необязательное* | `string` | Дополнительные данные в формате JSON-строки. Отправляются серверу бота в сообщении [`message_new`](../../../community-events/json-schema.md#message_new) в поле `payload`. Максимальная длина — 255 символов. Строка должна начинаться и заканчиваться фигурными скобками. |

Для кнопки можно указать [цвет](../keyboard.md#%D0%A6%D0%B2%D0%B5%D1%82%D0%B0%20%D0%BA%D0%BD%D0%BE%D0%BF%D0%BE%D0%BA).

## <a id="location"></a>location

Открывает диалоговое окно с информацией о местоположении. Пользователь может выбрать местоположение и отправить его в чат.

- Администраторы сообщества получат изображение карты в чате.
- Координаты точки придут на сервер бота в событии [`message_new`](../../../community-events/json-schema.md#message_new) в поле `message.geo.coordinates`.

Ряд, в котором находится кнопка `location`, может содержать не больше 2 кнопок. Иначе при вызове `messages.send` будет возвращена ошибка.

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` *обязательное* | `string` | Тип кнопки. Значение: `location`. |
| `payload` *необязательное* | `string` | Дополнительные данные в формате JSON-строки. Отправляются серверу бота в сообщении [`message_new`](../../../community-events/json-schema.md#message_new) в поле `payload`. Максимальная длина — 255 символов. Строка должна начинаться и заканчиваться фигурными скобками. |

## <a id="vkpay"></a>vkpay

Открывает окно оплаты VK Pay с предопределёнными параметрами. На кнопке отображается текст «Оплатить через VK Pay» и логотип VK Pay.

Кнопка `vkpay` должна быть единственной в строке. Иначе при вызове `messages.send` будет возвращена ошибка.

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` *обязательное* | `string` | Тип кнопки. Значение: `vkpay`. |
| `hash` *обязательное* | `string` | Строка с [параметрами платежа VK Pay](https://dev.vk.ru/ru/pay/getting-started) и идентификатором приложения в параметре `aid`, разделёнными символом `&`. Пример: `action=transfer-to-group&group_id=1&aid=10`. |
| `payload` *необязательное* | `string` | Дополнительные данные в формате JSON-строки. Отправляются серверу бота в сообщении [`message_new`](../../../community-events/json-schema.md#message_new) в поле `payload`. Максимальная длина — 255 символов. Строка должна начинаться и заканчиваться фигурными скобками. |

## <a id="open_link"></a>open\_link

Открывает ссылку, указанную в поле `link`.

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` *обязательное* | `string` | Тип кнопки. Значение: `open_link`. |
| `link` *обязательное* | `string` | URL, который будет открыт при нажатии на кнопку. |
| `label` *обязательное* | `string` | Текст кнопки. |
| `payload` *необязательное* | `string` | Дополнительные данные в формате JSON-строки. Отправляются серверу бота в сообщении [`message_new`](../../../community-events/json-schema.md#message_new) в поле `payload`. Максимальная длина — 255 символов. Строка должна начинаться и заканчиваться фигурными скобками. |

## <a id="open_app"></a>open\_app

Открывает мини-приложение или игру по идентификатору, указанному в параметре `app_id`.

Мини-приложение, добавленное в сообщество, может передавать данные боту через Callback или LongPoll API. Подробнее — в разделе [Взаимодействие с приложением](../app-interaction.md).

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` *обязательное* | `string` | Тип кнопки. Значение: `open_app`. |
| `app_id` *обязательное* | `integer` | Идентификатор мини-приложения или игры. [Где найти идентификатор приложения?](https://dev.vk.ru/ru/mini-apps/settings/overview#%D0%93%D0%B4%D0%B5%20%D0%BD%D0%B0%D0%B9%D1%82%D0%B8%20ID%20%D0%BC%D0%B8%D0%BD%D0%B8-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F?) |
| `label` *обязательное* | `string` | Текст кнопки, например `Играть`. |
| `owner_id` *необязательное* | `integer` | Идентификатор сообщества, в котором установлено приложение, если его требуется открыть в контексте сообщества. [Где найти идентификатор сообщества?](https://vk.ru/away.php?to=https%3A%2F%2Fvk.com%2Ffaq18062) |
| `hash` *необязательное* | `string` | Хеш для навигации в приложении, он будет передан в строке параметров запуска после символа `#`. |
| `payload` *необязательное* | `string` | Дополнительные данные в формате JSON-строки. Отправляются серверу бота в сообщении [`message_new`](../../../community-events/json-schema.md#message_new) в поле `payload`. Максимальная длина — 255 символов. Строка должна начинаться и заканчиваться фигурными скобками. |

## <a id="callback"></a>callback

Callback-кнопки позволяют обрабатывать нажатия без отправки пользователем сообщения в чат.На сервер бота отправляется событие [`message_event`](../../../community-events/json-schema.md#message_event), содержащее информацию о нажатии кнопки. Используйте `payload` для идентификации кнопки и выполнения серверной логики. Подробнее — в разделе [Работа с callback-кнопками](callback-keys.md).

| Поле | Тип | Описание |
| --- | --- | --- |
| `type` *обязательное* | `string` | Тип кнопки. Значение: `callback`. |
| `label` *обязательное* | `string` | Текст кнопки. Максимальная длина — 40 символов. После нажатия на кнопку текст на ней сменяется курсором, означающим ожидание. |
| `payload` *необязательное* | `string` | Дополнительные данные в формате JSON-строки. Отправляются серверу бота в сообщении [`message_new`](../../../community-events/json-schema.md#message_new) в поле `payload`. Максимальная длина — 255 символов. Строка должна начинаться и заканчиваться фигурными скобками. Если на клавиатуре несколько `callback`-кнопок, используйте это значение, чтобы идентифицировать кнопку, которую нажал пользователь. |

Для кнопки можно указать [цвет](../keyboard.md#%D0%A6%D0%B2%D0%B5%D1%82%D0%B0%20%D0%BA%D0%BD%D0%BE%D0%BF%D0%BE%D0%BA).
