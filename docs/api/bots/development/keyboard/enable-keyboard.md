## <a id="Включите клавиатуру в настройках сообщества"></a>Включите клавиатуру в настройках сообщества

Чтобы клавиатура отображалась в окне чата, включите её:

1. Откройте ваше сообщество ВКонтакте.
2. Перейдите на страницу **Управление → Сообщения** и включите **Сообщения сообществ**.






   Сохраните изменения.
3. Переключитесь в раздел **Управление → Сообщения → Настройки для бота** и включите **Возможности ботов**.






   Вы можете поставить галочку в пункте **Добавить кнопку «Начать»**. В этом случае клавиатура по умолчанию будет содержать кнопку «Начать».






   Сохраните изменения.

Теперь вы можете добавлять клавиатуру к сообщениям.

## <a id="Добавьте клавиатуру к сообщениям"></a>Добавьте клавиатуру к сообщениям

Чтобы добавить клавиатуру к сообщению, используйте [API ВКонтакте](https://dev.vk.ru/ru/reference): отправьте ответ пользователю с помощью API-запроса [`messages.send`](../../../../method/messages.send.md) и укажите желаемую конфигурацию кнопок в параметре `keyboard` этого запроса. Параметр принимает данные в виде JSON-строки. Подробнее о формате объектов и их свойствах — в разделе [Парамеры клавиатуры](../keyboard.md#%D0%9F%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B%20%D0%BA%D0%BB%D0%B0%D0%B2%D0%B8%D0%B0%D1%82%D1%83%D1%80%D1%8B).

Если параметр `keyboard` передан неверно, запрос [`messages.send`](../../../../method/messages.send.md) вернёт ошибку `911. Keyboard format is invalid`.
