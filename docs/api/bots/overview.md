# Обзор

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/api/bots/overview)

Боты — это программы, которые автоматизируют рутинные задачи. С их помощью можно принять заказ в интернет-магазине, прислать подборку видеороликов, посоветовать подходящие концерты или ближайший ресторан.

Чат-бот ВКонтакте — это скрипт на вашем сервере, который получает уведомления о событиях из ВКонтакте и обрабатывает их. Например, распознаёт команду в сообщении пользователя и отправляет ответ: текст, изображение или клавиатуру.

ВКонтакте боты общаются с пользователями через [сообщения сообществ](../community-messages/getting-started.md). Это простой и привычный для пользователя интерфейс.

Бот будет полезен, если вы хотите:

- Обрабатывать много однотипных обращений.
- Организовывать рассылки для подписчиков.
- Фильтровать заявки в службе поддержки.
- Мгновенно реагировать на сообщения.

Это самые распространённые сценарии. На практике бот может решать задачи сообщества любой тематики — от поддержки и продаж до интерактивных механик.

> Бот может стать дополнительным инструментом продвижения. Создавайте интерактивные сценарии, отправляйте мультимедиа, подключайте сторонние API — пользователи охотнее взаимодействуют с полезными и «живыми» механиками.

## <a id="Преимущества платформы"></a>Преимущества платформы

### <a id="Социальный граф"></a>Социальный граф

ВКонтакте позволяет работать с социальным графом и интересами пользователей. Это полезно, например, для рекомендаций или персонализированных сценариев.

### <a id="Мультимедиа"></a>Мультимедиа

ВКонтакте предоставляет доступ к большому объёму медиаконтента, который можно использовать в ответах бота: фотографии, видео и аудиозаписи.

### <a id="Кроссплатформенность"></a>Кроссплатформенность

Сообщения сообществ работают в веб-версии, мобильной версии и официальных приложениях. Пользователь может общаться с ботом на любой платформе.

## <a id="Примеры ботов"></a>Примеры ботов

- Бот [Сберкот](https://vk.ru/away.php?to=https%3A%2F%2Fvk.me%2Fsberkot) делится контентом, предлагает установить статус и получить стикеры.
- Бот [Авиасейлс](https://vk.ru/away.php?to=https%3A%2F%2Fvk.me%2Faviasales) помогает с изменением даты вылета, возвратом билета и обращениями в поддержку.
