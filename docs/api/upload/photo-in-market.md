# Загрузка изображения товара

[Оглавление](../../README.md) · [Оригинал VK](https://dev.vk.ru/ru/api/upload/photo-in-market)

Сообщества могут размещать информацию о товарах и услугах, а также давать пользователям возможность выбрать способ доставки, оплаты, вводить промокоды, а владельцам — вести учёт заказов.

Вы можете загрузить фотографии товаров, используя API ВКонтакте. Для этого можно использовать два набора API-операций, которые будут рассмотрены ниже.

## <a id="Требования и ограничения"></a>Требования и ограничения

Вне зависимости от выбранного вами подхода ВКонтакте предъявляет следующие требования к загружаемым изображениям товаров.

- Допустимые форматы: JPG, PNG, GIF.
- Минимальный размер фотографии — 400×400 px.
- Сумма высоты и ширины — не более 14 000 px.
- Объём файла — не более 50 Мбайт.
- Соотношение сторон — не более 1:20.

## <a id="1. Получите URL для загрузки изображения"></a>1. Получите URL для загрузки изображения

Для оптимизации нагрузки на серверы и подсистемы ВКонтакте использует разные адреса для загрузки файлов. Чтобы получить адрес для загрузки вашего изображения, отправьте API-запрос [`market.getProductPhotoUploadServer`](../../method/market.getProductPhotoUploadServer.md). Укажите следующие параметры:

| Параметр | Описание |
| --- | --- |
| `group_id` | Идентификатор сообщества, в котором находится товар. Найти идентификатор можно в URL сообщества: откройте страницу сообщества в браузере и скопируйте номер из адресной строки. Он указан после слова `club`.  Не указывайте минус перед номером. |
| `bulk` | Указывает, нужно ли загрузить несколько файлов. Если передаётся `true`, то в ответе вернётся адрес сервера, на который можно загрузить до 5 фотографий. |
| `v` | Версия API для запроса. Последняя версия: 5.199. |

### <a id="Пример запроса"></a>Пример запроса

```bash
curl -X POST 'https://api.vk.ru/method/market.getProductPhotoUploadServer' \
  -H 'Authorization: Bearer <КЛЮЧ_ДОСТУПА>' \
  -F 'group_id=12345' \
  -F 'v=5.199'
```

### <a id="Ответ сервера"></a>Ответ сервера

В ответе придёт объект с полем `upload_url`, которое содержит адрес для загрузки изображения.

```json
{
    "response": {
        "upload_url": "https://pu.vk.ru/gu-s/photo/v2/upload?token=eyJ0eXAiOiJKV1...6KmDD2CcXgZhimJYj5kE"
    }
}
```

Если в запросе был передан параметр `bulk="true"`, адрес сервера в ответе будет содержать `bulk_upload` вместо `upload`.

## <a id="2. Отправьте изображение"></a>2. Отправьте изображение

Для загрузки изображения отправьте файл изображения по адресу, полученному на [предыдущем шаге](photo-in-market.md#%D0%9E%D1%82%D0%B2%D0%B5%D1%82%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%B0).

| Компоненты запроса | Значение |
| --- | --- |
| Адрес | URL, полученный на [предыдущем шаге](photo-in-market.md#%D0%9E%D1%82%D0%B2%D0%B5%D1%82%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%B0) в поле ответа `upload_url`. |
| Тип HTTP-запроса | `POST` |
| Заголовок `Content-Type` | `multipart/form-data` |
| Параметр `file` | Адрес файла изображения на диске. Если вы загружаете несколько фотографий, передавайте их в формате `file1,file2...` |

### <a id="Пример запроса"></a>Пример запроса

Пример загрузки одного файла:

```bash
curl -X POST 'https://pu.vk.ru/gu-s/photo/v2/upload?token=eyJ0eXAiOiJKV1...6KmDD2CcXgZhimJYj5kE' \
  -F 'file=@C:/path/file-name.png'
```

Пример загрузки нескольких файлов:

```bash
curl -X POST 'https://pu.vk.ru/gu-s/photo/v2/bulk_upload?token=eyJ0eXAiOiJKV1...6KmDD2CcXgZhimJYj5kE' \
  -F 'file1=@C:/path/file-name1.png' \
  -F 'file2=@C:/path/file-name2.png' \
  -F 'file3=@C:/path/file-name3.png'
```

### <a id="Ответ"></a>Ответ

В ответе вернётся объект, содержащий служебную информацию о загруженном изображении. Этот ответ используется полностью на [следующем шаге](photo-in-market.md#3.%20%D0%A1%D0%BE%D1%85%D1%80%D0%B0%D0%BD%D0%B8%D1%82%D0%B5%20%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5). Использовать отдельные поля не нужно.

Пример ответа:

```json
{
    "sha":"cf76807b476a8bf9837dfe3d30224eecff6750abea7a074465a16277",
    "secret":"-3067663671768861774",
    "meta":{
        "height":"512",
        "kid":"8b0a87e178ebb61cec2b356a57649538",
        "width":"512"
    },
    "hash":"96af183d04798c3f60e5eade42a5f7bd",
    "server":"220921",
    "user_id":743784479,
    "group_id":23456789,
    "request_id":"983245c7a464fcda45d5f640ac8973e8",
    "album_id":-53,
    "app_id":62...87
}
```

При загрузке нескольких фотографий вернется массив с информацией по каждому файлу.

## <a id="3. Сохраните изображение"></a>3. Сохраните изображение

На этом этапе надо сохранить загруженную фотографию в системный альбом. Чтобы это сделать, выполните API-запрос [`market.saveProductPhoto`](https://dev.vk.ru/ru/method/market.saveProductPhoto) или [`market.saveProductPhotoBulk`](https://dev.vk.ru/ru/method/market.saveProductPhotoBulk), если вы загружали несколько фотографий, со следующими параметрами:

| Параметр | Описание |
| --- | --- |
| `upload_response` | Содержимое ответа, полученного на предыдущем этапе. Скопируйте и вставьте весь JSON-код, который вы получили. **Обратите внимание:** в зависимости от используемого инструмента отправки запроса вам может потребоваться экранировать кавычки, то есть заменить символы `"` на `\"`. |
| `v` | Версия API для запроса. Последняя версия: 5.199. |

Пример:

```bash
curl -X POST 'https://api.vk.ru/method/market.saveProductPhoto' \
  -H 'Authorization: Bearer <КЛЮЧ_ДОСТУПА>' \
  -F 'upload_response={"sha":"cf76807b476a8bf9837dfe3d30224eecff6750abea7a074465a16277","secret":"-3067663671768861774","meta":{"height":"512","kid":"8b0a87e178ebb61cec2b356a57649538","width":"512"},"hash":"96af183d04798c3f60e5eade42a5f7bd","server":"220921","user_id":743784479,"group_id":23456789,"request_id":"983245c7a464fcda45d5f640ac8973e8","album_id":-53,"app_id":62...87}' \
  -F 'v=5.199'
```

### <a id="Ответ"></a>Ответ

При успешном выполнении сервер ВКонтакте поместит картинку во временный системный альбом и в ответе вернёт объект со свойством `photo_id` — идентификатор загруженного изображения. Вы можете использовать его в дальнейшем, чтобы прикрепить изображение к товару.

```json
{"response":
    {
        "photo_id":457239024
    }
}
```

Если вы сохраняли несколько фотографий, в ответе вернётся массив объектов.

## <a id="4. Прикрепите изображение к товару"></a>4. Прикрепите изображение к товару

Прикрепить изображение к товару можно с помощью следующих API-запросов:

- [`market.add`](https://dev.vk.ru/ru/method/market.add) — создаёт товар.
- [`market.edit`](https://dev.vk.ru/ru/method/market.edit) — изменяет информацию о товаре.

Оба запроса используют параметры `main_photo_id` и `photo_ids`. Укажите в них идентификатор изображения, который вы получили на предыдущем шаге в поле `photo_id`.

### <a id="Пример запроса"></a>Пример запроса

```bash
curl -X POST 'https://api.vk.ru/method/market.edit' \
  -H 'Authorization: Bearer <КЛЮЧ_ДОСТУПА>' \
  -F 'owner_id=-123456' \
  -F 'item_id=10243117' \
  -F 'main_photo_id=457239024' \
  -F 'v=5.199'
```

### <a id="Пример ответа"></a>Пример ответа

```json
{
  "response":1
}
```
